أنشئ موقع البورتفوليو الخاص بك باستخدام Bootstrap خطوة بخطوة

بسم الله نبدأ. في نهاية هذا الدليل سيكون لديك موقع بورتفوليو حقيقي يتكيّف مع الهاتف والحاسوب. لا تقلق إن كنت لا تعرف كل شيء بعد، فسننطلق من الصفر.

كيف تستعمل هذا الدليل
  1. كل خطوة تبني جزءًا من الموقع نفسه: بورتفوليو ياسين بن علي، طالب من الجزائر العاصمة (هذا هو المشروع الذي نبنيه طوال الدليل).
  2. الكود في كل جزء قابل للتعديل: غيّره وستتحدّث النتيجة فورًا.
  3. في نهاية كل خطوة توجد تحديات من الأسهل إلى الأصعب. حاول أولًا، ثم اضغط على «عرض التصحيح».
  4. في الخطوة 9 تجتمع كل الأجزاء في ملف index.html واحد يمكنك تحميله.

ملاحظة: تحتاج إلى اتصال بالإنترنت لأن Bootstrap يُحمَّل من CDN (خادم يستضيفه لنا).

ملاحظة أخرى: نصوص الموقع نفسه (الأزرار والعناوين) كتبناها بالفرنسية عمدًا، لأن كثيرًا من المواقع الجزائرية بالفرنسية. أما الشروحات والتعليقات فبالعربية. وفي آخر الدليل تحدٍّ لتحويل الموقع كله إلى العربية من اليمين إلى اليسار.

0 تجهيز مساحة العمل

الهدف: أن يكون لديك مجلد وملف index.html، وأن تعرف كيف تعرضه في المتصفح.
  1. ثبّت Visual Studio Code (محرر مجاني) ومتصفحًا (Chrome أو Firefox).
  2. أنشئ مجلدًا باسم portfolio على سطح المكتب.
  3. في VS Code: File ← Open Folder، اختر portfolio، ثم أنشئ ملفًا جديدًا باسم index.html.
  4. لمشاهدة موقعك: انقر نقرًا مزدوجًا على index.html في مستكشف الملفات، فيُفتح في المتصفح.
  5. بعد كل تعديل: Ctrl + S في VS Code للحفظ، ثم F5 في المتصفح للتحديث.
نصيحة: في ملف HTML فارغ داخل VS Code، اكتب ! ثم اضغط Tab. سيكتب لك VS Code هيكل الصفحة تلقائيًا.

1 هيكل HTML مع Bootstrap

الهدف: صفحة فارغة لكنها جاهزة: Bootstrap محمَّل ويعمل.

لماذا Bootstrap؟ بدونه ستحتاج إلى كتابة مئات الأسطر من CSS للحصول على قائمة أو بطاقات أو تخطيط يتكيّف مع الهاتف. يوفّر Bootstrap كل ذلك على شكل كلاسات (classes) جاهزة: تكتب class="btn btn-primary" فتحصل على زر جميل.

الكود

الشرح سطرًا بسطر

<!DOCTYPE html>
تخبر المتصفح: «هذه صفحة HTML حديثة».
<html lang="fr">
لغة الصفحة. تفيد الترجمة الآلية وقارئات الشاشة. (لو كان موقعك بالعربية فستكتب ar.)
<meta charset="UTF-8">
تسمح بعرض الحروف المشكّلة (é, è, à) والعربية بشكل صحيح.
<meta name="viewport" ...>
ضرورية جدًا. بدونها تظهر الصفحة صغيرة جدًا على الهاتف، كأنها موقع حاسوب مصغَّر.
<title>
النص الذي يظهر في تبويب المتصفح.
<link ... bootstrap.min.css>
يحمّل كل أنماط Bootstrap من الإنترنت. @5.3.3 تثبّت الإصدار حتى لا يتغيّر موقعك من تلقاء نفسه.
<link ... bootstrap-icons>
يحمّل الأيقونات (كلاسات bi bi-...).
class="container py-5"
container يوسّط المحتوى ويحدّ من عرضه. py-5 يضيف مسافة في الأعلى والأسفل (p = padding، y = عمودي، 5 = كبيرة).
text-primary، lead
اللون الرئيسي للعنوان، ونص تمهيدي أكبر قليلًا.
btn btn-primary
زر Bootstrap بلون رئيسي. اكتب دائمًا الكلاسين معًا: btn ثم النوع.
<script ... bundle.min.js>
سلوكيات Bootstrap (قائمة الهامبرغر وغيرها). نضعه في نهاية body لتظهر الصفحة أولًا.

الكود

الشرح سطرًا بسطر

navbar navbar-expand-lg
navbar = شريط القائمة. expand-lg = القائمة ممتدّة على الشاشات الكبيرة، ومخفية خلف الهامبرغر في الأصغر.
bg-white border-bottom
خلفية بيضاء وخط رفيع في الأسفل.
fixed-top
تبقى القائمة ملتصقة بالأعلى عند النزول في الصفحة.
container
يحاذي القائمة مع بقية المحتوى.
navbar-brand
اسمك أو شعارك.
navbar-toggler
زر الهامبرغر. يبقى مخفيًا على الشاشات الكبيرة.
data-bs-toggle="collapse" + data-bs-target="#menu"
تقولان لـ Bootstrap: «عند النقر، افتح/أغلق العنصر الذي له المعرّف menu». يجب أن يكون الاسمان متطابقين.
collapse navbar-collapse + id="menu"
الجزء القابل للطيّ من القائمة. معرّفه id يطابق data-bs-target.
navbar-nav ms-auto
قائمة الروابط. ms-auto (margin-start auto) تدفعها إلى الطرف المقابل للبداية.
nav-item / nav-link
عنصر في القائمة ورابطه.
href="#apropos"
رابط إلى قسم في الصفحة نفسها: العلامة # تبحث عن العنصر الذي معرّفه apropos.

3 قسم الواجهة (Hero)

الهدف: عنوان تعريفي كبير وزرّان ودائرة بأحرف اسمك الأولى (ستضع صورتك لاحقًا).

أولًا: فهم شبكة Bootstrap

يقسّم Bootstrap كل سطر إلى 12 عمودًا. الـ row (السطر) يحتوي على col (أعمدة). إذا كتبت col-md-8 و col-md-4 فالمجموع 8 + 4 = 12: عمودان متجاوران. الحرفان md يعنيان «ابتداءً من الشاشة المتوسطة». وعلى الهاتف تتراصّ الأعمدة تلقائيًا الواحد تحت الآخر.

9 التجميع النهائي والتخصيص

الهدف: جمع كل الأجزاء في ملف واحد وإضفاء طابعك الشخصي عليه.

هذه هي الصفحة الكاملة: الهيكل (خطوة 1) + القائمة (2) + الواجهة (3) + نبذة عني (4) + المهارات (5) + المشاريع (6) + التواصل (7) + التذييل (8) + الـ CSS الخاص بنا داخل <style>. يمكنك تعديلها هنا ثم تحميلها.

الـ CSS الخاص بنا، مشروحًا

:root { --bs-primary: ... }
تغيّر اللون الرئيسي لـ Bootstrap (الشارات والأشرطة والنصوص...).
.btn-primary { ... }، .btn-outline-primary { ... }
لا يربط Bootstrap الأزرار بهذا المتغيّر، لذلك نعطي اللون للأزرار أيضًا، بما في ذلك عند تمرير الفأرة (hover).
html { scroll-behavior: smooth }
عند النقر على رابط في القائمة تنزلق الصفحة بنعومة.
section { scroll-margin-top: 70px }
تمنع القائمة الثابتة من إخفاء عنوان القسم الذي نصل إليه.

التحديات النهائية

استبدل الأخضر بالأزرق في الموقع كله بعملية واحدة.

التحدي 2: صورتك الحقيقية متوسط

استبدل دائرة الأحرف بصورتك، ضعها في المجلد نفسه الذي فيه index.html.

عرض التصحيح

ضعها مكان <div class="avatar ...">YB</div>. object-fit: cover تمنع تشوّه الصورة. والنص alt يصف الصورة (إتاحة الوصول).

التحدي 3: نشر الموقع على الإنترنت أصعب

انشر البورتفوليو مجانًا لترسل الرابط إلى زبائنك وأصحاب العمل.

عرض التصحيح
  1. تأكد أن اسم الملف هو index.html وأن الصورة في المجلد نفسه.
  2. الطريقة السهلة: Netlify Drop. تسحب مجلد portfolio إلى الصفحة فتحصل على رابط.
  3. طريقة المطوّرين: أنشئ مستودعًا على GitHub، وارفع ملفاتك إليه، ثم فعّل GitHub Pages من إعدادات المستودع.
  4. جرّب الرابط على هاتفك قبل مشاركته.

تحدٍّ إضافي: موقع بالعربية من اليمين إلى اليسار أصعب

حوّل الموقع كله إلى العربية. يحتاج ذلك إلى تغييرين في <head> ثم ترجمة النصوص.

عرض التصحيح

dir="rtl" تجعل الصفحة من اليمين إلى اليسار، ونسخة bootstrap.rtl.min.css تقلب الأعمدة والمحاذاة تلقائيًا. هذا هو سبب تسمية Bootstrap لكلاساته ms وme وtext-start (البداية والنهاية) بدل اليسار واليمين: تنقلب معها دون أن تغيّر شيئًا. بعدها ترجم نصوص الموقع إلى العربية.

مبروك! لقد بنيت موقعًا كاملًا. الخطوة التالية: استبدل النصوص التجريبية بمشاريعك الحقيقية مع لقطات الشاشة.
