Crée ton portfolio avec Bootstrap, étape par étape

Bismillah, on commence. À la fin de ce guide, tu auras un vrai site portfolio qui s'adapte au téléphone et à l'ordinateur. Tu ne sais pas encore tout ? Matkhafch, on repart de zéro.

Comment utiliser ce guide
  1. Chaque étape construit une partie du même site : le portfolio de Yacine Benali, étudiant à Alger (le fil rouge).
  2. Le code de chaque partie est modifiable : change-le et le résultat à droite se met à jour.
  3. À la fin de chaque étape, des défis du plus facile au plus dur. Cherche d'abord, puis clique sur « Voir la correction ».
  4. À l'étape 9, toutes les parties s'assemblent en un fichier index.html que tu peux télécharger.

Important : il faut une connexion internet, car Bootstrap est chargé depuis un CDN (un serveur qui l'héberge pour nous).

0 Préparer ton espace de travail

Objectif : avoir un dossier, un fichier index.html et savoir l'afficher dans le navigateur.
  1. Installe Visual Studio Code (éditeur gratuit) et un navigateur (Chrome ou Firefox).
  2. Crée un dossier portfolio sur ton Bureau.
  3. Dans VS Code : Fichier → Ouvrir un dossier, choisis portfolio, puis crée un nouveau fichier nommé index.html.
  4. Pour voir ton site : double-clique sur index.html dans l'explorateur de fichiers. Il s'ouvre dans le navigateur.
  5. Après chaque modification : Ctrl + S dans VS Code pour sauvegarder, puis F5 dans le navigateur pour rafraîchir.
Astuce : dans un fichier HTML vide de VS Code, tape ! puis la touche Tab. VS Code écrit tout seul le squelette d'une page.

1 Le squelette HTML avec Bootstrap

Objectif : une page vide mais prête : Bootstrap est chargé et fonctionne.

Pourquoi Bootstrap ? Sans lui, il faudrait écrire des centaines de lignes de CSS pour avoir un menu, des cartes ou une mise en page qui s'adapte au mobile. Bootstrap fournit tout cela sous forme de classes prêtes à l'emploi : tu écris class="btn btn-primary" et tu obtiens un joli bouton.

Le code

Explication ligne par ligne

<!DOCTYPE html>
Dit au navigateur : « c'est une page HTML moderne ».
<html lang="fr">
La langue de la page. Utile pour la traduction automatique et les lecteurs d'écran.
<meta charset="UTF-8">
Permet d'afficher correctement les accents (é, è, à) et même l'arabe.
<meta name="viewport" ...>
Indispensable. Sans elle, sur téléphone la page s'affiche toute petite, comme un site d'ordinateur rétréci.
<title>
Le texte de l'onglet du navigateur.
<link ... bootstrap.min.css>
Charge tous les styles de Bootstrap depuis internet. @5.3.3 fixe la version pour que ton site ne change pas tout seul.
<link ... bootstrap-icons>
Charge les icônes (classes bi bi-...).
class="container py-5"
container centre le contenu et limite sa largeur. py-5 ajoute de l'espace en haut et en bas (p = padding, y = vertical, 5 = grand).
text-primary, lead
Couleur principale pour le titre, et texte d'introduction un peu plus grand.
btn btn-primary
Un bouton Bootstrap de couleur principale. Il faut toujours les deux classes : btn puis la variante.
<script ... bundle.min.js>
Les comportements de Bootstrap (menu hamburger, etc.). On le met à la fin du body pour que la page s'affiche d'abord.

Défis

Défi 1 : personnaliser Facile

Change le <title> en « Portfolio de [ton prénom] » et le titre h1 en « Salam, je suis [ton prénom] ! ».

Voir la correction

Défi 2 : un gros bouton vert Moyen

Voir la correction

btn-success = vert, btn-lg = grand.

Défi 3 : bouton avec icône Plus dur

Voir la correction

2 Le menu de navigation

Objectif : un menu en haut de page qui devient un bouton « hamburger » sur téléphone.

À partir d'ici, on ne montre que le contenu du <body>. Colle chaque partie dans ton index.html, entre <body> et le <script> de Bootstrap, l'une sous l'autre.

Le code

Clique sur « Mobile » dans le résultat, puis sur le bouton hamburger.

Explication ligne par ligne

navbar navbar-expand-lg
navbar = barre de menu. expand-lg = menu étalé sur grand écran, caché derrière le hamburger en dessous.
bg-white border-bottom
Fond blanc et un fin trait en bas.
fixed-top
Le menu reste collé en haut quand on descend dans la page.
container
Aligne le menu avec le reste du contenu.
navbar-brand
Ton nom ou le logo, à gauche.
navbar-toggler
Le bouton hamburger. Il reste caché sur grand écran.
data-bs-toggle="collapse" + data-bs-target="#menu"
Disent à Bootstrap : « au clic, ouvre/ferme l'élément qui a l'id menu ». Les deux noms doivent être identiques.
collapse navbar-collapse + id="menu"
La partie du menu qui se replie. Son id correspond au data-bs-target.
navbar-nav ms-auto
La liste des liens. ms-auto (margin-start auto) les pousse à droite.
nav-item / nav-link
Un élément de la liste et son lien.
href="#apropos"
Un lien vers une section de la même page : le # cherche l'élément qui a l'id apropos.

Défi 1 : ton nom Facile

Mets ton propre nom dans la marque du menu.

Voir la correction

Défi 2 : un lien de plus Moyen

Ajoute un lien « CV » à la fin du menu.

Voir la correction

À placer avec les autres <li>, à l'intérieur du <ul>. Le lien ne mènera nulle part tant qu'une section id="cv" n'existe pas.

Défi 3 : menu sombre Plus dur

Fais un menu à fond noir avec du texte clair (indice : la doc Bootstrap 5.3 parle de data-bs-theme).

Voir la correction

3 La section d'accueil (hero)

Objectif : un grand titre de présentation, deux boutons, et un cercle avec tes initiales (tu mettras ta photo plus tard).

D'abord, comprendre la grille Bootstrap

Bootstrap découpe chaque ligne en 12 colonnes. Une row (ligne) contient des col (colonnes). Si tu écris col-md-8 et col-md-4, tu obtiens 8 + 4 = 12 : deux colonnes côte à côte. Le md veut dire « à partir d'un écran moyen ». Sur téléphone, les colonnes s'empilent l'une sous l'autre, automatiquement.

Explication ligne par ligne

id="accueil"
Le point d'arrivée du lien #accueil du menu.
bg-light pt-5
Fond gris très clair, et espace en haut (pt = padding-top) pour ne pas passer sous le menu fixe.
container py-5 mt-4
Contenu centré, avec de l'espace vertical (py-5) et une marge en haut (mt-4).
row align-items-center g-4
Une ligne. align-items-center centre les colonnes verticalement, g-4 (gap) laisse de l'espace entre elles.
col-md-8 / col-md-4
Texte sur 8 colonnes, cercle sur 4 (total 12).
display-4 fw-bold
Un très grand titre (display-4) en gras (fw-bold = font-weight bold).
lead text-secondary
Paragraphe d'intro plus grand, en gris.
btn btn-primary btn-lg me-2
Gros bouton plein. me-2 (margin-end) met un petit espace à droite.
btn-outline-primary
Bouton « vide » avec seulement un contour.
rounded-circle d-inline-flex align-items-center justify-content-center
Forme ronde, et centrage des initiales à l'intérieur du cercle (on y reviendra avec « flex »).

Défi 1 : changer les proportions Facile

Donne 7 colonnes au texte et 5 au cercle.

Voir la correction

Défi 2 : un bouton CV Moyen

Ajoute un troisième bouton gris « Télécharger mon CV » avec une icône de téléchargement.

Voir la correction

mt-2 évite que les boutons se collent quand ils passent à la ligne sur petit écran.

Défi 3 : texte centré sur mobile Plus dur

Centre le texte sur téléphone, mais garde-le aligné à gauche sur ordinateur.

Voir la correction

Une section de la page. L'id doit être exactement celui du lien du menu, sans le #.

Grand espace au-dessus et en dessous. Les espacements vont de 0 à 5.

Le code

Explication ligne par ligne

badge text-bg-primary
Une petite étiquette colorée. text-bg-primary règle le fond et la couleur du texte.

Explication ligne par ligne

Une grille « automatique » : row-cols-1 = 1 carte par ligne sur mobile, row-cols-md-3 = 3 par ligne dès l'écran moyen. Plus besoin de calculer les col-md-4.

7 Le formulaire de contact

Objectif : un formulaire propre, et tes coordonnées à côté.

Le code

Dans la démo, l'envoi est bloqué pour ne pas ouvrir ta messagerie. Sur ton vrai site, il fonctionnera.

Explication ligne par ligne

<form action="mailto:...">
Au clic sur « Envoyer », le logiciel de mail du visiteur s'ouvre avec le message prêt. C'est simple, mais ça ne marche que si le visiteur a une messagerie configurée. Plus tard, tu pourras utiliser un service comme Formspree.
<label for="nom"> + id="nom"
Le for du label et l'id du champ doivent être identiques : cliquer sur le texte active le champ.
form-label / form-control
Les styles Bootstrap du texte et des champs (largeur 100 %, bordures arrondies).
mb-3
Espace entre deux champs.
type="email"
Le navigateur vérifie tout seul qu'il y a un @.
required
Le champ ne peut pas rester vide.
<textarea rows="4">
Une zone de texte sur 4 lignes.
col-lg-5 offset-lg-1 mt-4 mt-lg-0
Colonne des coordonnées, décalée d'1 colonne sur grand écran, avec une marge en haut seulement sur mobile.

9 L'assemblage final et la personnalisation

Objectif : réunir toutes les parties dans un seul fichier et le rendre personnel.

Voici la page complète : squelette (étape 1) + menu (2) + accueil (3) + à propos (4) + compétences (5) + projets (6) + contact (7) + pied de page (8) + le CSS perso dans <style>. Tu peux la modifier ici, puis la télécharger.

Le CSS perso, expliqué

:root { --bs-primary: ... }
Change la couleur principale de Bootstrap (badges, barres, textes, etc.).
.btn-primary { ... }, .btn-outline-primary { ... }
Bootstrap ne relie pas les boutons à cette variable : on donne donc aussi la couleur aux boutons, y compris au survol (hover).
html { scroll-behavior: smooth }
Quand on clique un lien du menu, la page glisse doucement.
section { scroll-margin-top: 70px }
Évite que le menu fixe cache le titre de la section où on arrive.

Les 6 erreurs classiques (et comment les corriger)

SymptômeCause probableSolution
Le site est minuscule sur téléphoneLigne viewport oubliéeRemets la balise <meta name="viewport" ...> dans le <head>.
Le hamburger ne s'ouvre pasScript Bootstrap oublié, ou data-bs-target ≠ idVérifie le <script> en bas de page et que #menu correspond à id="menu".
Les colonnes ne s'alignent pascol placée hors d'une rowStructure : container > row > col.
Aucun style BootstrapPas de connexion, ou faute dans l'URL du <link>Vérifie internet et recopie l'URL exactement.
